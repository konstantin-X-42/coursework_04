# Сервис управления рассылками «MailingService» <img width="137" height="41" alt="Skypro" src="https://github.com/user-attachments/assets/ac708293-d4d3-4222-980d-a89643052ae0" />

Веб-приложение для создания, планирования и автоматической фоновой отправки рассылок клиентам. Проект реализован в рамках курсовой работы на базе веб-фреймворка **Django** и реляционной СУБД **PostgreSQL**.

## 🚀 Основной функционал (Выполнение ТЗ)

### 1. Управление рассылками (CRUD)
* Полноценное управление сущностями: **Клиенты (Получатели)**, **Сообщения (Шаблоны писем)**, **Рассылки (Параметры и расписание)**.
* Современный и адаптивный графический интерфейс, разработанный на базе фреймворка **Bootstrap 5**.
* Интерактивные HTML5-календари в формах для удобного выбора даты и времени старта/окончания рассылки.
* Автоматический динамический расчет статуса рассылки (`Создана`, `Запущена`, `Завершена`) на основе текущего времени.

### 2. Кастомная авторизация и Личный кабинет
* Стандартный пользователь Django переопределен: авторизация на сайте происходит по **Email** (поле `username` полностью удалено).
* Расширенный профиль пользователя в Личном кабинете с поддержкой загрузки картинок и полей: `Телефон`, `Страна`, `Аватар`.
* Реализована полноценная **верификация аккаунта по email**: при регистрации генерируется уникальный токен, а учетная запись активируется только после перехода по ссылке из письма.

### 3. Разграничение прав доступа (Контроль владения)
* Каждый созданный объект (клиент, сообщение, рассылка) жестко привязан к своему создателю (`owner`).
* Обычные пользователи имеют доступ на просмотр и редактирование исключительно **своих собственных** записей.
* Реализована системная роль **Менеджера** (через Django Permissions). Менеджеры и Администраторы имеют право просматривать любые рассылки и списки пользователей в системе, но лишены прав на их создание, изменение или удаление.

### 4. Автоматическая фоновая отправка (Вместо Cron/Redis)
* Внутрь приложения интегрирован фоновый асинхронный планировщик задач **APScheduler** (`django-apscheduler`).
* Планировщик автоматически просыпается каждую минуту, проверяет актуальные рассылки в PostgreSQL, имитирует отправку писем и фиксирует подробные отчеты в модель логов (`MailingLog`).
* Все результаты попыток с ответами сервера мгновенно выводятся в интерактивную карточку «История отправки» на странице просмотра рассылки.

## 💻 Инструкция по локальному развертыванию

### 1. Клонирование проекта и установка зависимостей
Убедитесь, что у вас установлен менеджер пакетов `Poetry`. В терминале PyCharm выполните:
```bash
# Установка всех изолированных библиотек проекта из poetry.lock
poetry install
```

### 2. Настройка базы данных PostgreSQL
1. Откройте **pgAdmin 4** и создайте чистую базу данных с именем `coursework_04`.
2. Откройте файл `config/settings.py` и при необходимости подкорректируйте доступы в блоке `DATABASES` (укажите ваш пароль от PostgreSQL):
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'coursework_04',
        'USER': 'postgres',
        'PASSWORD': 'ваш_пароль_от_postgres',
        'HOST': '127.0.0.1',
        'PORT': '5432',
    }
}
```

### 3. Применение миграций архитектуры БД
Создайте структуру таблиц в PostgreSQL, включая служебные таблицы планировщика:
```bash
python manage.py migrate
```

### 4. Создание Главного Администратора (Суперпользователя)
Запустите команду создания суперадмина. Консоль запросит ввод Email и Пароля (авторизация по Email активна):
```bash
python manage.py createsuperuser
```

### 5. Запуск локального веб-сервера
Включите сервер разработки Django:
```bash
python manage.py runserver
```
При успешном запуске в консоли отобразится системное уведомление:  
`🚀 Фоновый планировщик рассылок успешно запущен!`

## 📧 Тестирование логики отправки писем

* **Локальный тест (Консоль):** Для удобства защиты проекта перед преподавателем в `settings.py` активирован консольный бэкенд писем (`EmailBackend`). Все ссылки верификации пользователей и тексты рассылок отправляются напрямую в терминал **Run** внутри PyCharm.
* **Проверка отправки:** Чтобы проверить планировщик, создайте клиента, напишите сообщение, а в параметрах рассылки укажите время старта на 1 минуту вперед в календаре и выделите пользователя синим цветом. Ровно в указанную минуту в консоли PyCharm отобразится текст письма, а на сайте в истории рассылки появится зеленый статус **«Успешно»**.

* Главная страница: [http://127.0.0.1:8000/](http://127.0.0)
* Административная панель Django: [http://127.0.0.1:8000/admin/](http://127.0.0admin/)
